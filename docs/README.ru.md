# Paraverse

Paraverse превращает сохранение одной игры Paradox в стартовый мод для следующей. Можно пройти всю цепочку **CK3 → EU5 → Victoria 3 → HOI4** или перенести кампанию из CK3 сразу в Victoria 3.

**[Скачать Paraverse 1.0 для Windows](https://github.com/chuppka/Paraverse-Releases/releases/download/v1.0/Paraverse-1.0.exe)**

## Как начать

1. Запусти `Paraverse-1.0.exe`. Для переноса понадобятся установленные исходная и целевая игры. Приложение работает офлайн.
2. Перетащи сохранение в окно, выбери файл вручную или нажми **Добавить последнее сохранение**. Укажи следующую игру и проверь пути к папкам игр.
3. Проверь кампанию, нажми **Создать мод**, затем **Установить мод**. В EU5 включи его в меню **Модификации и дополнения**. Для Victoria 3 и HOI4 нажми **Открыть лаунчер** и включи мод в игровом наборе Paradox Launcher.
4. Начни **новую кампанию** с включённым модом. Для следующего переноса сохранись в игре и открой этот сейв в Paraverse.

Переключиться на русский можно кнопкой **Русский** на левой панели. Для CK3 нужен ручной сейв с текстовым `gamestate`. Поддерживаемые форматы, версии игр и список переносимых механик есть в [основном README](../README.md#game-versions-and-saves).

## Если что-то пошло не так

Открой **Подробности → Скопировать диагностику**. В [сообщении об ошибке](https://github.com/chuppka/Paraverse-Releases/issues/new) укажи маршрут переноса, приложи скопированный текст и опиши, как повторить ошибку. Приложение маскирует локальные пути и имя сохранения в скопированной диагностике.
